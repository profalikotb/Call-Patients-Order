# نظام الدور الذكي – أ.د. على قطب على
**Prof. Ali Kotb – Smart Patient Queue System**

نظام إدارة دور ونداء صوتي بصوت رجالي مصري لعيادات جراحة المخ والأعصاب.
Next.js 15 · TypeScript · Tailwind · Supabase (Postgres + Realtime) · Google Sheets API · Azure Neural TTS `ar-EG-ShakirNeural` · Vercel · PWA

---

## ١. المعمارية باختصار

```
Google Sheet (الحجوزات – المصدر الوحيد)          لا قاعدة بيانات مرضى موازية
        │  قراءة فقط كل 10 ث (حساب خدمة)
        ▼
/api/sync ──► queue_sync()  ─┐
                              │  Postgres (Supabase) – حالة الدور الحية فقط
لوحة الاستقبال ─► /api/queue/action ─► queue_apply()  ← قفل صف (العيادة،اليوم) + رقم إصدار + مفتاح منع التكرار
                              │
                              ▼
                     display_state  (أرقام فقط – بلا أسماء)  ──Realtime──►  شاشة الانتظار + كل أجهزة الاستقبال
                                                                         │
                                         /api/tts/number ◄───────────────┘ (جهاز صوت واحد فقط – Lease)
                                         Azure ar-EG-ShakirNeural  →  كاش في Supabase Storage
```

| قرار | السبب |
|---|---|
| كل انتقال للدور دالة SQL واحدة `queue_apply` مع `SELECT … FOR UPDATE` | ضغطتان متزامنتان من جهازين لا يمكن أن تناديا مريضين أو مريضاً مرتين (مُختبر بـ 10 طلبات متزامنة) |
| `expectedVersion` + `idem` لكل ضغطة | الضغط المزدوج أو إعادة الإرسال بعد انقطاع الشبكة يُنفَّذ مرة واحدة |
| هوية الحجز = `معرف الحجز` (أو بصمة: تاريخ+وقت+اسم+موبايل) | ترتيب الشيت أو إدراج صفوف أو إعادة الترقيم لا يُنتج تكرارات |
| الأرقام تتبع الموعد **حتى أول نداء** ثم تُجمَّد | المريض لا يرى رقمه يتغير بعد بدء الدور؛ الحجز المتأخر يأخذ الرقم التالي |
| `display_state` جدول عام منفصل بالأرقام فقط | Realtime للمتصفح بمفتاح anon بدون أي تعرض لبيانات المرضى (RLS + revoke) |
| Lease لجهاز الصوت (60 ث، نبض كل 20 ث) | جهاز واحد فقط يتكلم لكل عيادة؛ نقل الصوت لجهاز آخر بضغطة |
| الشاشة لا تنطق نداءً أقدم من 20 ث، ولا تنطق أي شيء عند أول تحميل | إعادة الاتصال أو إعادة تحميل الصفحة لا تنادي مريضاً خطأ |
| كل تغيير في Realtime مجرد «تنبيه» ← الشاشة تؤكد الحالة من الخادم قبل النطق | لا نداء من بيانات غير مؤكدة |
| قراءة فارغة للشيت لا تلغي حجوزات اليوم | خطأ في اسم التبويب أو عطل Google لا يمسح العيادة |

### السياسات
* **حسب الموعد** (افتراضي) · **حسب الوصول** (المريض «لم يصل» حتى تسجيل الوصول ثم يأخذ رقمه) · **أرقام يدوية**.
* الحالات: منتظر · تم النداء · داخل الكشف · تم الكشف · غائب · مؤجل · ملغي (+ «لم يصل» في سياسة الوصول).

## ٢. الإعداد خطوة بخطوة (≈ 30 دقيقة)

### أ) Supabase
1. أنشئ مشروعاً جديداً — **Region: Frankfurt (eu-central-1)** (الأقرب للقاهرة، ونفس منطقة Vercel `fra1`).
2. **SQL Editor** ← الصق محتوى `supabase/migrations/001_queue.sql` كاملاً ← Run.
3. **Database ▸ Replication / Publications**: تأكد أن `display_state` ضمن `supabase_realtime` (الملف يضيفه تلقائياً).
4. **Settings ▸ API**: انسخ `Project URL` و `anon key` و `service_role key`.

### ب) Google Sheet (اختر طريقة واحدة)
**١ – Sheets API (موصى به):**
1. [console.cloud.google.com](https://console.cloud.google.com) ← مشروع ← فعّل **Google Sheets API**.
2. IAM ▸ Service Accounts ▸ Create ← Keys ▸ Add key ▸ JSON.
3. من الملف: `client_email` ← `GOOGLE_SERVICE_ACCOUNT_EMAIL` ، `private_key` ← `GOOGLE_PRIVATE_KEY` (كما هو مع `\n`).
4. افتح شيت الحجوزات ← **Share** ← أضف بريد حساب الخدمة بصلاحية **Viewer** فقط.

**٢ – Apps Script (بدون Google Cloud):** انسخ `apps-script/QueueFeed.gs` داخل الشيت، اضبط `FEED_TOKEN`، انشره Web App، ثم `SHEET_SOURCE=appsscript`.

**أعمدة الشيت:** يتعرف تلقائياً على: معرف الحجز · التاريخ · الوقت · العيادة · الاسم · رقم واتساب · الإجراء (ومرادفاتها، مع تجاهل الهمزات والتاء المربوطة). أي اختلاف يُضبط من **الإعدادات ← ربط Google Sheet** مع معاينة فورية لصفوف اليوم.
**الإلغاء:** أي صف يحتوي في «الإجراء» أو «الحالة» على: ملغي/إلغاء/cancel… (قابلة للتعديل).

### ج) الصوت المصري (Azure AI Speech)
1. [portal.azure.com](https://portal.azure.com) ← Create ▸ **Speech service** ← Region مثل `westeurope` ← Pricing **F0 (مجاني)** يكفي عيادة (0.5 مليون حرف/شهر؛ كل نداء ≈ 40 حرفاً ويُدفع مرة واحدة بفضل الكاش).
2. Keys and Endpoint ← `AZURE_SPEECH_KEY` و `AZURE_SPEECH_REGION`.
3. الصوت: **`ar-EG-ShakirNeural`** — الصوت الرجالي الوحيد بلهجة مصرية في Azure. (أصوات ar-SA / ar-XA ليست مصرية – لم تُستخدم.)
4. اختياري: ElevenLabs بـ Voice ID لصوت رجالي مصري تختاره من مكتبتهم بعد الاستماع.
5. الاحتياطي الأخير: صوت المتصفح. على **Microsoft Edge** يتوفر «Microsoft Shakir Online (Natural) – Arabic (Egypt)» = نفس الصوت المصري مجاناً. الشاشة تُظهر تحذيراً إن اضطرت لصوت غير مصري.

### د) GitHub + Vercel
```bash
git init && git add . && git commit -m "Smart Patient Queue"
gh repo create prof-ali-kotb-smart-queue --private --source=. --push
```
Vercel ▸ Add New Project ▸ استورد المستودع ▸ **Environment Variables**: كل ما في `.env.example` ▸ Deploy.
`vercel.json` يثبّت الدوال في `fra1`.

### هـ) أول تشغيل
1. ادخل بـ `ADMIN_USERNAME` / `ADMIN_PASSWORD`.
2. **الإعدادات ← المستخدمون**: أنشئ حسابات الاستقبال (ويمكن تقييد كل موظف بعيادة).
3. **الإعدادات ← الصوت**: استمع لأرقام صعبة (١١، ١٢، ٨٨، ٣٠٠) ← اضبط السرعة ← **توليد 1–80** لتجهيز الكاش.
4. **الإعدادات ← الروابط**: انسخ رابط شاشة كل عيادة.

## ٣. تشغيل شاشة الانتظار (التلفزيون)
* أفضل خيار: Mini-PC أو Android TV Box عليه **Chrome/Edge** متصل HDMI ← افتح رابط الشاشة ← **تفعيل الصوت** (مرة واحدة) ← تدخل ملء الشاشة وتمنع إطفاء الشاشة (Wake Lock).
* Chrome بدون ضغطة إطلاقاً (Kiosk):
  `chrome --kiosk --autoplay-policy=no-user-gesture-required "https://…/display/heliopolis?k=…"`
* شاشة ثانية للعرض فقط: «عرض فقط بدون صوت».
* نقل الصوت لجهاز آخر: افتح الرابط عليه ← تفعيل الصوت ← «نقل الصوت لهذه الشاشة».
* عند انقطاع الإنترنت: تعرض آخر حالة مؤكدة بشريط أحمر، وعند العودة تتأكد من الخادم ولا تنطق أي نداء قديم.

| مرضى اليوم لا يظهرون | التاريخ نص بصيغة MM/dd أو العيادة باسم مختلف | «صيغة التاريخ النصي» · أضف الاسم في «قيم عمود العيادة» |

| صوت غير مصري | Azure غير مضبوط فاستُخدم صوت المتصفح | اضبط `AZURE_SPEECH_*` أو شغّل الشاشة على Edge |
| أول مقطع مقطوع على التلفزيون | HDMI يوقظ السماعات متأخراً | مُعالج بـ 250ms صمت أولي + نغمة التنبيه – أبقِ النغمة مفعّلة |
| «تم تعديل الدور من جهاز آخر» | جهازان ضغطا نداء التالي معاً | سلوك صحيح: نُفذ نداء واحد فقط |
| رقم الشاشة لا يتحدث | Realtime غير مفعّل لـ `display_state` | Database ▸ Publications ▸ supabase_realtime (يوجد أيضاً تحديث احتياطي كل 15 ث) |
| `server_error: Supabase is not configured` | متغيرات Vercel ناقصة | أضفها ثم **Redeploy** |

## ٧. الخصوصية والأمان
* بيانات المرضى لا تُخزن إلا ما يلزم لليوم (اسم، موبايل، وقت) ويقرأها الخادم فقط بمفتاح service_role.
* الشاشة العامة لا تستقبل أي اسم أو رقم هاتف — حتى في وضع «ذكر الاسم» يُولَّد الصوت على الخادم ولا يُحفظ ولا يُرسل الاسم كنص.
* مفاتيح Google وAzure وSupabase service_role في متغيرات Vercel فقط. الدوال محجوبة عن anon (`revoke execute`).
* الجلسات JWT في Cookie ‏httpOnly (14 ساعة)، كلمات المرور scrypt.

## ٨. حدود معروفة / تطوير مقترح
* المزامنة تعتمد على وجود لوحة استقبال مفتوحة (كل 10 ث). للعمل بدونها: n8n أو cron خارجي يستدعي `/api/sync`.
* لا يوجد حد لمحاولات الدخول سوى تأخير ثابت — استخدم كلمات مرور قوية أو Vercel Firewall.
* إرسال واتساب «دورك اقترب» عند وصول الدور لـ N مرضى قبله: سهل الإضافة عبر n8n على `announcements`.

## ٩. الربط مع Oracle عبر شيت WaitingListToday
الشيت `1UElEujRJx1BPAc4ZYsi62vgpcHnLk2NYztAxgIyqoj8` يُغذّى مباشرة من Oracle (`CLINICS` على DRALIKOTB) بالسكريبت `apps-script/WaitingListToday_PDF.gs`:

| التبويب | المحتوى | الاستخدام |
|---|---|---|
| `QUEUE_TODAY` | **كل** حجوزات اليوم من `VISITS_LIST` + الاسم والتليفون من `PATIENT_REC` + «العيادة» حسب اليوم | مصدر نظام الدور (ثابت – لا يحذف من تم كشفه، حتى لا يُلغى المريض في الدور) |
| `PENDING_TODAY` | من لم يُسجَّل له `VISIT_REC` اليوم | متابعة الانتظار |

* نفس مشروع Apps Script يحتوي `doGet` (بديل `QueueFeed.gs`) ← انشره Web App ← `SHEET_SOURCE=appsscript` + `APPS_SCRIPT_FEED_URL` + `APPS_SCRIPT_FEED_TOKEN` (= `FEED_TOKEN` من سجل `saveConfig`).
* أو Sheets API: `GOOGLE_SHEET_ID` = معرف الشيت أعلاه + مشاركة الشيت مع حساب الخدمة (Viewer).
* التبويب الافتراضي أصبح `QUEUE_TODAY` (يمكن تغييره من الإعدادات ← ربط Google Sheet).
* لا يوجد عمود وقت في Oracle ← الترتيب حسب «رقم الحجز» (NUMBER10).
* «العيادة» تُستنتج من يوم الأسبوع (`CLINIC_BY_DAY` في السكريبت): الجمعة = طوخ، السبت/الأحد/الثلاثاء = مصر الجديدة، الاثنين = وادي النيل (خارج نظام الدور).
